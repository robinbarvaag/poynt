<objective>
Build the post-purchase experience: confirmation page, onboarding wizard, and Stripe Customer Portal integration for subscription self-service management.

Purpose: After a user purchases a membership (Plan 01 checkout + Plan 02 webhooks), they need a clear path from payment to product usage. Output: Confirmation page at `/medlemskap/bekreftelse`, enhanced onboarding wizard at `/on-poynt/onboarding`, Customer Portal API route, updated membership settings page, and onboarding completion tracking in Payload Users.

**1. Create Customer Portal API route (`apps/web/app/api/customer-portal/route.ts`):**

POST endpoint that creates a Stripe Customer Portal session for the authenticated user.

Implementation:
- Import `getStripe` from `@poynt/stripe`
- Import `auth` from `@poynt/planner-auth/server` for session checking
- Import `getPayload` from 'payload' and config
- Get the user's session via `auth.api.getSession({ headers: req.headers })`
- If no session, return 401
- Find the Payload user by email to get `stripeCustomerId`
- If no stripeCustomerId, return 400 with error "Ingen Stripe-kundekonto funnet" (No Stripe customer account found)
- Create billing portal session:
  ```typescript
  const session = await stripe.billingPortal.sessions.create({
    customer: stripeCustomerId,
    return_url: `${process.env.NEXT_PUBLIC_URL || 'http://localhost:3000'}/on-poynt/innstillinger/medlemskap`,
  });
  ```
- Return `{ url: session.url }`
- Wrap in try/catch, return 500 on Stripe errors
