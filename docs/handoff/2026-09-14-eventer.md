## Feller (i tillegg til de i EVENTER.md)

1. **Seed-scripts overskriver innhold.** Susanne har redigert ALT innhold manuelt. Kjør aldri et
   seed-script som oppdaterer eksisterende dokumenter (f.eks. `seed-personvern.ts`). Seed bare helt nytt
   innhold, create-only. Endringer i eksisterende innhold gjøres i admin.
2. **Ikke POST til `/api/eventer/[id]/pamelding` med falske adresser** — `.env.local` har ekte
   `RESEND_API_KEY`. Test logikk med `payload run` og `$env:RESEND_API_KEY=''`, eller bruk Robins egne
   adresser (`robinbarvaag+noe@gmail.com`).
3. **Typesjekk:** `bun run typecheck` (turbo). Aldri `bunx tsc` fra rotmappa.
4. **Git Bash gjør `/sti` om til Windows-sti** når den sendes som argument — bruk `MSYS_NO_PATHCONV=1`.
5. **Scripts kan ikke tømme Next-cachen** (`revalidateTag` kaster utenfor Next). Endrer et script et
   event, viser eventsiden gammel data til noen lagrer eventet i admin.
6. **Dev-serveren krasjer** når `/api/og-image` kalles lokalt (`sharp` mangler Windows-binær). Ikke
   eventer-relatert.
7. **Mobiltest av kamera krever https:** cloudflared quick tunnel (`cloudflared.exe tunnel --url
   http://localhost:3000`, ingen konto) + dev-server med `NEXT_PUBLIC_URL=<tunnel-url>` og midlertidig
   `allowedDevOrigins: ["*.trycloudflare.com"]` i `next.config.mjs` (fjernet igjen — ikke commit).
8. **`git rm` + `git add` på samme sti** feiler med «pathspec did not match»; bruk `git add -A -- <stier>`.
